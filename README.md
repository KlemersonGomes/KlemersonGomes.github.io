## Executando localmente

Para executar este projeto no seu computador, é necessário ter o Node.js instalado.

```bash
git clone https://github.com/KlemersonGomes/KlemersonGomes.github.io.git
cd KlemersonGomes.github.io
npm install
npm run dev
